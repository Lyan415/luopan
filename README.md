# 🧭 後天八卦二十四山風水羅盤

一個單一 HTML 檔案的手機版電子羅盤工具。可將傳統二十四山羅盤疊加在自行上傳的平面圖或現場照片上，用於格局定向、方位標註與截圖記錄。

無需安裝、無需後端、無外部相依套件，開啟網頁即可使用。

**線上使用**：https://Lyan415.github.io/luopan/

---

## 功能

| 功能 | 說明 |
|---|---|
| 🔴 中心紅點 | 羅盤正中央固定一個不透明紅點，作為定位基準 |
| 🔍 自由縮放 | 雙指縮放，或使用 `＋` / `－` 按鈕 |
| 🔄 自由旋轉 | 雙指扭轉，或使用 `↺15` / `↺1` / `1↻` / `15↻` 按鈕微調 |
| ✋ 位置調整 | 直接拖曳移動，或用方向鍵微調；`◎` 鍵可只重設位置 |
| 🎯 度數定向 | 輸入 0–359.9 任一度數，該度數立即轉至畫面正上方 |
| 🧭 方位感測 | 顯示手機頂端目前朝向的度數；可一鍵將該方位轉至正上方 |
| 📡 自動跟隨 | 開啟後羅盤隨手機轉動即時對正實際方位，如同實體羅盤 |
| 🖼️ 底圖編輯 | 上傳圖片作為底圖，可拖曳、縮放、旋轉；畫面所見範圍即為裁切結果 |
| 🔁 更換底圖 | 隨時重新上傳替換，羅盤設定不受影響 |
| 📏 紅色直線 | 可新增多條（上限 12 條）可自由旋轉的紅色參考線，用於標示座向或分界 |
| 💾 存成圖片 | 輸出 PNG。輸出圖**不含任何功能鍵**，但會保留羅盤角度、手機方位與各紅線角度 |
| 👁️ 淨空模式 | 一鍵隱藏所有操作介面，全螢幕檢視 |
| 🌓 背景深淺 | 深色／淺色底切換 |

## 使用方式

### 在手機上開啟

直接以手機瀏覽器開啟網址即可。建議加入主畫面，使用起來與原生 App 相同：

- **iPhone（Safari）**：分享鍵 → 加入主畫面
- **Android（Chrome）**：右上角選單 → 加到主畫面

### 基本操作流程

1. 切到 **🖼️ 底圖** 頁籤 → 上傳平面圖或現場照片 → 拖曳／縮放／旋轉調整到定位
2. 切到 **☯ 羅盤** 頁籤 → 調整羅盤大小與位置，使中心紅點對準量測基準點
3. 定向，擇一方式：
   - 直接輸入度數，按「轉到正上方」
   - 切到 **🧭 方位** 頁籤 → 啟用感測 → 按「將目前方位轉到正上方」，或開啟「自動跟隨」
4. 需要標示座向時，切到 **📏 紅線** 頁籤新增紅線，拖曳畫面即可旋轉指向
5. 按 **💾 存圖** 輸出結果

## 度數對應

羅盤圖面採傳統 **南上北下** 配置，子山 0° 位於圖面下方，度數在圖面上以逆時針方向遞增（午 180° 在上、卯 90° 在左、酉 270° 在右）。

「轉到正上方」的換算即依此圖面配置計算，輸入的度數會精準對應到圖上實際印製的刻度。

## 方位感測說明

「方位」功能依賴裝置的磁力感測器，有以下限制：

- 必須在 **HTTPS** 環境下開啟（GitHub Pages 已符合；以 `file://` 本機開啟則無法使用）
- iOS 會跳出「動作與方向」權限請求，需允許
- 部分 App 內嵌瀏覽器（如社群軟體內建瀏覽器）取不到感測資料，請改用 Safari 或 Chrome 開啟
- 磁力感測易受金屬結構、電子設備、磁鐵干擾，讀數僅供參考；精密定向請以實體羅盤或專業儀器為準

若裝置不支援，其餘所有功能（含手動輸入度數定向）仍可正常使用。

## 存圖行為

輸出時會另以離屏畫布重繪一次，因此**操作介面不會出現在圖片中**，僅保留左上角的角度資訊。

依執行環境不同，存檔方式為：

- **iOS**：跳出分享選單 → 選「儲存影像」存入相簿
- **Android**：直接下載至相簿／下載資料夾
- 若瀏覽器不支援上述方式，可改用手機截圖功能保存（「淨空模式」可先隱藏介面）

## 部署

本專案為單一 HTML 檔，部署到 GitHub Pages 的步驟：

1. 建立一個新的 repository（Public）
2. 上傳 `index.html` 至根目錄
3. Settings → Pages → Source 選擇 `Deploy from a branch`，Branch 選 `main` / `(root)`，Save
4. 約一分鐘後即可透過 `https://<帳號>.github.io/<repo 名稱>/` 存取

亦可直接下載 `index.html` 以任何瀏覽器開啟離線使用（方位感測功能除外）。

## 技術說明

- 純前端單一檔案，無框架、無 CDN、無外部相依
- 羅盤圖形為 SVG，以 Base64 內嵌於 HTML 中，離線亦可正常顯示
- 繪圖使用 HTML5 Canvas，底圖與羅盤為獨立圖層，各自保有位置／縮放／旋轉狀態
- 手勢以 Pointer Events 實作，支援單指拖曳與雙指縮放旋轉
- 重繪以 `requestAnimationFrame` 節流，確保大張照片下仍維持流暢
- 方位讀取優先採用絕對方位事件（`deviceorientationabsolute` / `webkitCompassHeading`）

**上傳的底圖僅在瀏覽器本機處理，不會上傳至任何伺服器。**
